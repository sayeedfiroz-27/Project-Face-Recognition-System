# Dataset Folder

This folder stores captured face images.

When you run `python3 src/01_capture_images.py`, the script creates one folder for each registered user.

Example structure:

```text
dataset/
  1_Rahul/
    1.jpg
    2.jpg
    3.jpg
  2_Priya/
    1.jpg
    2.jpg
    3.jpg
```

Real face images are not included in GitHub for privacy. Students should capture their own consent-based images during the practical session.
