Face Recognition System Project

Step-by-step classroom project using Python, OpenCV, Machine Learning, Webcam Capture, Recognition, Attendance and Result Saving.

Project Purpose

Is project ka purpose students ko real-world computer vision workflow samjhana hai. Hum face detect karenge, webcam se images capture karenge, model train karenge, registered users ko identify karenge, attendance mark karenge aur results save karenge.

Full detailed notes with every topic, code and line-by-line explanation are available in face_recognition_system_notes.md.

Install

python3 -m pip install -r requirements.txt

Run Step by Step

python3 src/01_capture_images.py
python3 src/02_train_model.py
python3 src/03_recognize_and_attendance.py

Project Files

src/01_capture_images.py captures user face images from webcam.

src/02_train_model.py trains the LBPH face recognition model.

src/03_recognize_and_attendance.py recognizes registered users and marks attendance.
